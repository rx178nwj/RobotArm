# マルチI2Cブリッジ 制御回路（KiCad）

[design_spec.md](../docs/design_spec.md) v0.1 §6（電気仕様）および
[i2c_architecture.md](../docs/i2c_architecture.md) §11（確定事項）に基づく回路図・基板。

- `multi_i2c_bridge.kicad_pro` / `multi_i2c_bridge.kicad_sch` / `multi_i2c_bridge.kicad_pcb` — KiCad 8 以降で開けます
- シンボル・フットプリントは全てファイルに埋め込み済み（外部ライブラリ不要）
- `generate_schematic.py` — 回路図の生成スクリプト（再生成用）

## PCB（50×50mm・2層）

- 外形 50×50mm、M2.5取付穴×4、両面GNDベタゾーン（KiCad上で `B` キーで再充填）
- **配線済み（自作オートルータ`route_pcb.py`による全自動配線）**
  - 全39ネット配線完了・セグメント626本・ビア100個（うちGNDステッチ43個+スタブ39本）
  - 設計ルール: 信号0.2mm / 電源(3V3系)0.25mm / クリアランス0.15mm / ビア0.6/0.3mm
  - GND: 配線せず両面ベタ+各SMD GNDパッド脇ビア接続（RP2040 EPにビア4個）
  - RP2040西側GPIO 8本は0.4→0.9mmピッチの階段状ファンアウトでB面へ引出し
  - `verify_pcb.py`（独立検証）で接続性=分断ネット0・クリアランス違反0を確認済み
  - **KiCad上でゾーン充填(`B`)→DRC実行を必ず行うこと**（ベタとの最終整合確認）
- パッケージ方針（2026-07-10 指定）:
  - RP2040関連コンデンサ（デカップリングC1-C12・水晶C13/C14）= **0402**
  - LED・抵抗・その他チップ = **0603**（電源ダイオードD1/D2のみ電流容量のためSMA）
  - センサハーネス用コネクタ J2-J4 = **JST PH（2.0mmピッチ, B5B-PH-K）**
  - 上位コネクタ J1 = JST XH 4P（指定はセンサ側のみのため現状XH。PH統一なら要指示）
- 配置概要: 上辺=USB+電源(LDO)、左辺=J1上位コネクタ、中央=RP2040+デカップリングリング、
  左中=フラッシュ+水晶、右=TCA9548A+プルアップ列+J2-J4、下辺=RESET/BOOTボタン+SWD
- ⚠ フットプリントは自動生成（寸法は標準値ベース）。**USB Micro-B・JST PH/XH・TL3342は
  発注前に実部品のデータシートと照合すること**

## 回路構成

| ブロック | 部品 | 仕様上の根拠 |
|---------|------|--------------|
| ブリッジMCU | U1 RP2040 (QFN-56) | design_spec §7 で確定 |
| QSPIフラッシュ | U2 W25Q128JVSIQ | RP2040は外部Flash必須（§6.3） |
| クロック | Y1 12MHz (ABM8) + 27pF×2 + 1kΩ | RP2040 Hardware design guide 準拠 |
| I2C mux | U3 TCA9548APWR, アドレス0x70 (A0-A2=GND) | §3/§4 |
| mux RESET | GP4 駆動 + 10kプルアップ (R11) | §6.3 |
| 角度センサ | U5-U7 AS5600 ×3（別基板・参考記載） | VDD5V-VDD3V3短絡=3.3V動作必須、100nF近傍、OTP不使用のため10µF省略（§6.1） |
| DIR制御 | GP5/6/7 → 各ch独立、10kプルダウン (R18-20) | §6.4（ブート中フロート防止） |
| 電源 | USB VBUS / J1の5V をショットキーOR → AP2112K-3.3 | 全系3.3V統一（§6.1） |
| 書込/デバッグ | USB Micro-B (BOOTSEL) + SWDヘッダ + RESET/BOOTボタン | — |
| 状態LED | GP25 → LED1 | — |

## I2Cプルアップ（design_spec §6.2 の根拠通り）

| バス | 抵抗 | 値 |
|------|------|----|
| 上流（Controller⇔RP2040, GP0/GP1） | R7, R8 | 2.2kΩ（ホスト側実装時はDNP） |
| ブリッジ⇔mux（GP2/GP3） | R9, R10 | 4.7kΩ |
| mux各chセグメント（ch0-2） | R12-R17 | 2.2kΩ（10kΩはtr違反リスクで不採用） |

※ AS5600モジュール側にプルアップ実装済みの場合は並列合成値に注意（下がり過ぎ防止のためch側をDNP調整）。

## GPIO割当（design_spec §6.4 の通り）

GP0/1=上流I2C0、GP2/3=下流I2C1、GP4=mux RESET、GP5-7=DIR ch0-2、GP25=状態LED。
GP8-24/26-29は未使用（将来のPIO並列I2C移行用に6本予約可、i2c_architecture §5.6）。

## コネクタ

| Ref | 用途 | ピン配列 |
|-----|------|---------|
| J1 | 上位コントローラ | 1:5V_IN 2:GND 3:SCL 4:SDA（JST-XH 4P） |
| J2-J4 | センサch0-2 | 1:3V3 2:GND 3:SCL 4:SDA 5:DIR（JST-XH 5P） |
| J8 | SWD | 1:SWCLK 2:GND 3:SWDIO |
| J9 | USB Micro-B | ファーム書込（BOOTSEL）・給電 |

## 設計上の仮定（要確認）

1. **電源**: 仕様書は「全系3.3V」だが供給元の記載がないため、**J1またはUSBから5Vを受けて基板上LDOで3.3V生成**とした。上位から3.3V直給電にする場合はD2/U4をバイパスする改版が必要。
2. 上流レベルシフタ用フットプリント予約（i2c_architecture §11.1推奨）は未実装。5V系ホスト対応が必要になった時点で追加。
3. 割込み予約GPIO配線（i2c_architecture §7、任意）は未実装。
