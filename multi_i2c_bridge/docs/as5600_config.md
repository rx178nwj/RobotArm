## 1. 確定サマリ

| 設定項目 | 確定値 | 根拠 |
|----------|--------|------|
| 角度ソース | **RAW_ANGLE (0x0C/0x0D)** | OTP設定(ZPOS/MPOS/MANG)・境界ヒステリシス非依存で予測可能。スケーリングは上位で実施 |
| Slow Filter (SF) | **4x（暫定, ステップ応答 0.55ms）** | ⚠️**根拠は実機検証待ち**（§3）。RAW_ANGLE にSFフィルタが効くか未確定のため、選定根拠は現時点で保留 |
| Fast Filter (FTH) | **7 LSB（暫定）** | ⚠️**根拠は実機検証待ち**（§3）。RAW_ANGLE 採用時はフィルタが効かない可能性があり、値は暫定 |
| Power Mode (PM) | **NOM（常時測定）** | 低電力モードは測定間に5〜100msスリープが入り1kHz不可 |
| Watchdog (WD) | **OFF** | 自動低電力移行を無効化し常時動作を保証 |
| HYST | **OFF** | 生データを歪めない（必要なら上位でフィルタ） |
| 設定方法 | **レジスタ書き込み（揮発, OTP焼き込みなし）** | 起動時に毎回書込。センサは無改造・互換のまま |

## 2. CONFレジスタ値の算出

CONFは16bit（0x07=上位バイト, 0x08=下位バイト）。

| フィールド | ビット | 設定 | 2進 |
|-----------|-------|------|-----|
| PM（電源モード） | [1:0] | NOM | `00` |
| HYST（ヒステリシス） | [3:2] | OFF | `00` |
| OUTS（出力段） | [5:4] | 未使用(I2C運用) | `00` |
| PWMF（PWM周波数） | [7:6] | 未使用 | `00` |
| SF（Slow Filter） | [9:8] | 4x | `10` |
| FTH（Fast Filter Threshold） | [12:10] | 7 LSB | `010` |
| WD（Watchdog） | [13] | OFF | `0` |
| reserved | [15:14] | — | `00` |

**結果**：

```
CONF = 0b0000_1010_0000_0000 = 0x0A00
  レジスタ 0x07 (High) <= 0x0A
  レジスタ 0x08 (Low)  <= 0x00
```

> FTHエンコード参考: 000=OFF(スローのみ), 001=6, 010=7, 011=9, 111=10, 100=18, 101=21, 110=24 [LSB]。SFエンコード: 00=16x, 01=8x, 10=4x, 11=2x。

## 3. フィルタ選定の背景（SF）※根拠は実機検証待ち

> ⚠️ **本節の選定根拠（SF=4x を巡回周期に一致させる）は撤回・保留中。**
> データシート p.19 は RAW ANGLE を "unscaled and **unmodified**"、ANGLE を "scaled and **filtered**" と記述しており、**採用している RAW_ANGLE には SF/FTH フィルタが効かない可能性**がある。効かない場合、以下の「ステップ応答を巡回周期に一致させる」議論は RAW_ANGLE には適用されない。
>
> **暫定方針**：SF=4x / FTH=7LSB は CONF=0x0A00 の暫定値として維持するが、選定根拠は保留とする。RAW_ANGLE のフィルタ有無を実機で切り分け（SF値を変えて静止時ノイズが変化するか確認）、結果を踏まえて必要であれば根拠を再記載する。フィルタ効果が必要と判明した場合は ANGLE(0x0E/0x0F) への切替（[design_spec.md](design_spec.md) §5.2 CONFIG）も選択肢。

参考（データシート Figure 31。**ANGLE 使用時に効く**フィルタ特性。RAW での有効性は未確定）：

| SF | ステップ応答遅延 | 出力ノイズ(1σ, 概算) |
|----|----------------|---------------------|
| 16x | 2.2 ms | ~0.015° |
| 8x | 1.1 ms | ~0.021° |
| 4x | 0.55 ms | ~0.030° |
| 2x | 0.286 ms | ~0.043° |

## 4. RAW_ANGLE vs ANGLE

| | RAW_ANGLE (0x0C/0x0D) 採用 | ANGLE (0x0E/0x0F) |
|--|---------------------------|-------------------|
| スケーリング | なし（生12bit 0–4095） | ZPOS/MPOS/MANG適用 |
| 境界ヒステリシス | なし | あり（10LSB） |
| OTP依存 | なし（無設定でも予測可能） | あり |
| フィルタ(SF/FTH) | ⚠️**不明（効かない可能性）** | 適用される |

- ⚠️ データシート p.19 は RAW を "unscaled and **unmodified**"、ANGLE を "scaled and **filtered**" と記述。**RAW_ANGLE には SF/FTH フィルタが効かない可能性**があり、実機検証で確定させる（§3 参照）。
- ブリッジは生位置を転送し、角度範囲・オフセット・単位変換は上位で実施する方針。
- フィルタ効果が必要な場合は、ZPOS/MPOS を OTP書込せず（既定フルレンジ）ANGLE を使うことで、実質フルレンジのままフィルタのみ享受できる（0/360°境界の 10LSB ヒステリシスは受容）。

## 5. 起動時設定シーケンス（ch毎）

[software_architecture.md](software_architecture.md) §8.1 の手順4に対応。

```
# --- 全ch共通の最前段：電源投入後のパワーアップ待ち ---
wait >= 10 ms                               # T_PU (Power-up time) max 10ms（データシート Figure 10）
                                            # 最初のI2Cアクセス前に必ず待つ

# --- 全ch共通の前段：回転方向(DIR)を確定 ---
for ch in 0..2:
    gpio_set(DIR[ch], DIR_CONFIG.bit[ch])   # GP5/6/7 を駆動（0=L:CW増加 / 1=H:CCW増加）
                                            # CONF書込の「前」に確定させる（[design_spec.md](design_spec.md) §6.4）

for ch in 0..2:
    mux_select(ch)                       # TCA9548A(0x70) で ch選択
    read STATUS(0x0B)                    # MD(bit5)=1 磁石検出を確認
        MD=0 なら ch_ok[ch]=0 として継続（DEGRADED）
    write CONF: 0x07 <= 0x0A, 0x08 <= 0x00   # 揮発設定（OTP焼き込みなし）
    (option) read back 0x07/0x08 で 0x0A00 を検証
    read AGC(0x1A)                        # 磁石距離の妥当性確認（推奨中央付近）
```

> CONFは1トランザクションで 0x07 から2バイト連続書き込み可能。
> DIR は AS5600 内部レジスタではなく **ハード入力ピン**。ブリッジ側 GPIO で駆動し、フロート禁止（各線プルダウン10kΩ）。方向仕様と配線は [design_spec.md](design_spec.md) §6.4 を参照。

## 6. 使用レジスタまとめ（下流アクセス）

| アドレス | 名称 | R/W | 用途 |
|----------|------|-----|------|
| 0x07–0x08 | CONF | R/W | フィルタ/電源設定（起動時 0x0A00 書込） |
| 0x0B | STATUS | R | MD/ML/MH（磁石検出・強弱） |
| 0x0C–0x0D | RAW_ANGLE | R | **主データ**：生角度12bit `raw = ((0x0C & 0x0F)<<8) | 0x0D` |
| 0x1A | AGC | R | 磁石距離指標（間引き取得） |
| 0x1B–0x1C | MAGNITUDE | R | CORDIC振幅（診断用・任意） |

## 7. エンドツーエンド遅延（参考）

物理的な角度変化 → 上位取得までの最悪遅延：

| 要素 | 遅延 |
|------|------|
| AS5600 フィルタ整定（SF=4x, 定常時。⚠️RAW採用時は効かない可能性→§3） | ~0.55 ms |
| 下流ポーリング周期 | ~0.55 ms |
| 上流データ齢（非同期キャッシュ） | ~0.55 ms |
| **合計（最悪）** | **~1.6 ms** |

- ⚠️ フィルタ整定分（~0.55ms）は ANGLE 使用時の値。RAW_ANGLE が無フィルタと判明した場合、この項は消え合計は短くなる（一方で生ノイズは増える）。実機検証で確定させる。
- 大きな変化時は高速フィルタ（FTH）が効き、フィルタ整定分は短縮される（フィルタが効く場合）。
- 静止時は低ノイズを維持（フィルタが効く場合）。

## 8. 調整余地（実測でチューニング）

- FTH しきい値：実信号のノイズ・動作量に応じて 6〜18 LSB の範囲で調整。誤トリガ（ノイズで高速フィルタが暴れる）が出れば上げる、追従が鈍ければ下げる。
- SF：静止精度をさらに上げたい場合 8x、より低遅延が要る場合 2x。
- これらは実行時に上流レジスタ **`AS5600_CONF`(0x44/0x45, LE)**（[command_spec.md](command_spec.md) §4.8）で変更できる。SF/FTH のみ変更可（PM/WD 等は運用前提保護のため拒否）。書込値は Core1 が全6chの AS5600 CONF へ再書込する。角度ソース(RAW/ANGLE)の切替は別レジスタ `CONFIG`(0x40 bit0)。
  - ⚠ RAW_ANGLE 採用時は SF/FTH が効かない可能性があるため（§3）、フィルタ挙動の評価は `CONFIG` bit0=1（ANGLE）に切替えた上で `AS5600_CONF` を振って確認する。
